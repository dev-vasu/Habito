# User Preferences & Design Philosophy

## Design & Visual Standards
- **Always Present Visual Choices First**: Whenever deciding on UI/UX, themes, styling, or visual design, always present interactive visual prototypes/showcases featuring distinct, human-crafted artistic directions (e.g. Editorial Zen, Stealth Craft, Neo-Brutalist) so the user can see, feel, and decide.
- **Reject Generic "AI-Slop" Aesthetics**: Avoid cookie-cutter purple/indigo gradients, sterile rounded cards, and generic bot copy (*"Hola! 👋"*, *"Keep going champ!"*). Focus on genuine human craft, physical/tactile metaphors, authentic typography pairings, and intentional personality.
- **Interactive Demos**: Always give the user live, clickable prototypes to test tactile feedback before committing to code.
